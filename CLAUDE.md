See @AGENTS.md for project context and rules. See @PLAN.md for the implementation plan.

Key rules:
- Never print, log, or write real input values anywhere except the user's own input file.

- After each commit, check whether CLAUDE.md / AGENTS.md still describe the project correctly; if not, update them and commit that as `docs: ...`.
